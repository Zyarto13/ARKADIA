# Brand marks

The Spotify, Deezer, YouTube Music, Discord, Steam, Epic Games, and CurseForge vector paths in the app are based on Simple Icons, distributed under CC0 1.0:

- https://cdn.simpleicons.org/spotify/FFFFFF
- https://cdn.simpleicons.org/deezer/FFFFFF
- https://cdn.simpleicons.org/youtubemusic/FFFFFF
- https://cdn.simpleicons.org/discord/FFFFFF
- https://cdn.simpleicons.org/steam/FFFFFF
- https://cdn.simpleicons.org/epicgames/FFFFFF
- https://cdn.simpleicons.org/curseforge/FFFFFF

The ARKADIA mark in `arkadia-mark.svg` is original project artwork. Its Windows icon is generated from the same inverted-V mark.

The marks are used only as application UI icons. Company and product names and logos remain the property and trademarks of their respective owners. Minecraft is represented by a generic block motif rather than an official mark.
